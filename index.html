YouTube / Google

Personal Test Mode is ON: you can connect before full OAuth verification. API uploads stay Private until your YouTube API project passes its audit.
Enable YouTube Data API v3 and YouTube Analytics API in Google Cloud, then create an OAuth 2.0 Web client.
  1. Enable YouTube Data API v3 and YouTube Analytics API in the Google Cloud project.
  2. Create an OAuth 2.0 Web application client and add https://frymastercheese.github.io as an authorized JavaScript origin.
  3. In Google Auth Platform → Audience, keep the app in Testing and add the Google account that owns High Value Explained as a Test user.
  4. Testing-mode authorization can expire after 7 days, so reconnect when Google asks.
  5. Use privacy.html and terms.html for the app-policy pages.
  6. Until the YouTube API project passes its compliance audit, API-uploaded videos are restricted to Private. ClipFree enforces that automatically in Personal Test Mode.

What “fully automated” means here
