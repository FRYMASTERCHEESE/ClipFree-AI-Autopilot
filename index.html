What “fully automated” means here

The browser can generate, render, package and upload while this page is open. A static GitHub Pages site cannot reliably run a 24/7 background worker after your phone/laptop closes the tab. The included workflow therefore gives you a real one-click browser autopilot without pretending GitHub Pages is a permanent server.
